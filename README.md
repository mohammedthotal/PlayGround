## Murmur Pines: The Last Lantern

A small 3D forest adventure. Gather three lantern seeds on the far side of the stream, then return to the shrine before the three-minute nightfall. Echo pulses briefly reveal the hidden stepping-stone bridge and stun nearby spirits.

- **Move:** WASD or arrow keys (on phones, use the on-screen pad)
- **Hurry:** Shift
- **Echo pulse:** Space or E (on phones, tap **Echo Pulse**)

Open `index.html` from a local web server to play. Three.js is loaded from jsDelivr.
